# 离线分析的结论

数据见同目录的 `offline_summary.md`（由 `offline_analysis/offline_analysis.py` 从各阶段日志生成）。以下数字均来自该文件。

## 1. 停在哪一步：最后一轮就够了（方案 2.4）

- 所有方法的训练曲线在几百步后就平稳下来，用目标标签挑出的最优点只比最后一轮高 0.3–1.1 个点。
- 三种无标签选点规则（最小预测熵、最大 SND、最小全量 CORAL 距离）没有一种比“最后一轮”更好。“最小 CORAL 距离”对基线和 IM 最差，会选到第 100 步左右，因为那时 CORAL 距离还没增大，比最后一轮低 1.1–3.0 个点。
- 报告写法：原文报告最后一轮是合理的，不存在“靠目标标签挑停止点”的水分；早停在这个设置下没有必要。

## 2. 不用目标标签能不能选出 λ 和方法：不能（方案 4.4，假设 A4）

- 选 λ（λ = 0、原作者 λ、规则 λ、共用 λ）：
  - “最小预测熵”30 次里 29 次选了 λ = 0，因为 CORAL 会让预测变得不那么确定；
  - “最小 CORAL 距离”总是选最大的 λ（规则 λ 或共用 λ），因为它就是 CORAL 在优化的量；
  - “最大 SND”也大多选 λ = 0。
  - 三种规则都不如直接用原作者的 λ（遗憾值 1.2–2.6 对 0.2）。而原作者的 λ 很可能是看着目标结果调出来的，在无监督设定下拿不到。
- 选方法：“最小预测熵”和“最大 SND”大多选中 IM 类方法，平均 65.1–65.2，比固定用 CORAL + IM（66.4）还低；“最小 CORAL 距离”会选到规则 λ 的 Deep CORAL（57.8）。
- 报告写法：每个无标签指标都偏向“直接优化它”的方法或 λ，所以不能用来公平地比较方法或挑超参数。这把“λ 难以在无标签条件下确定”从一句批评变成了有数据的结论，也说明我们事先固定 β、γ 而不调参是必要的。

## 3. batch 上对齐了，不等于整个域对齐了（方案 3.2，假设 A3）

- 不做适应时，训练中看到的 batch CORAL 损失是全量距离的 1.5–2.7 倍；用 Deep CORAL 后变成 3.1–7.1 倍（A→W：0.064 对 0.009）。
- 这个放大来自两部分：评估模式下 batch 估计本身就偏大 1.3–3.7 倍（有限样本的协方差估计误差）；训练模式的 Dropout 再放大 1.2–2.0 倍。
- 真实距离越小，偏差占比越大。所以 CORAL 生效以后，训练后期最小化的 batch 损失大部分是估计噪声，而不是真实的域差异。
- fc8 对齐也顺带缩小了 fc7 的全量距离（A→W 从 2.8e-3 降到 4.0e-4）。
- 报告写法：这是 A3 不成立的直接证据，也说明原文图 2(b) 中的“两项损失大致相等”，比较的其实是分类损失和一个以噪声为主的量。

## 4. λ 过大时特征并没有“退化”（方案 3.3）

- 原文把 λ 过大时的性能下降归因于“退化特征”。如果真是这样，λ 越大，有效秩应越低。数据给出的是相反的结果：
  - D 作为源域、W 作为源域的任务上，规则 λ（约 0.6）比原作者 λ（0.0001–0.001）大几百到几千倍，目标 fc8 的有效秩从 23–24 升到 28–29（最大为 31）；
  - 同时准确率下降，D→A 从 50.9 降到 45.2，D→W 从 94.7 降到 92.3。
- CORAL 让目标 logits 的协方差去匹配源域。源域在训练集上已被完美分开，31 类各自分散，所以协方差谱接近“均匀”。强行匹配之后，目标预测在各类之间更分散、更不确定（A→W、A→D、D→A、W→A 四个任务平均，预测熵从原作者 λ 的 0.95 升到规则 λ 的 1.68），而不是塌缩到少数方向。
- fc7 的有效秩基本不随方法变化。
- 报告写法：λ 过大的害处不是秩塌缩，而是把源域“各类分得很开”的二阶结构硬套到了没有这种结构的目标特征上。原文“退化特征”的说法不准确。

## 5. 校准性：CORAL 和 IM 的作用方向相反（方案 4.3）

| | 准确率 | ECE | NLL |
|---|---|---|---|
| 基线 | 55.9 | 0.273 | 2.63 |
| Deep CORAL（原作者 λ） | 57.5 | 0.181 | 2.03 |
| Deep CORAL（规则 λ） | 54.9 | 0.066 | 1.75 |
| IM | 65.0 | 0.336 | 8.12 |
| CORAL + IM | 66.4 | 0.318 | 4.18 |

- CORAL 明显改善校准，λ 越大越明显：ECE 从 0.273 降到 0.066，但准确率可能下降。
- IM 让准确率大幅提高，校准却变差，NLL 高达 8.12，说明错误的预测也非常自信。
- 把 CORAL 加到 IM 上，准确率只多 1.4 个点，NLL 却减半（8.12 → 4.18）。
- 报告写法：CORAL 在 CORAL + IM 里的主要作用，可能不是提高准确率，而是抑制 IM 带来的过度自信。这给“CORAL + IM 比 IM 好”补充了一个准确率之外的理由。

## 没能做的部分

- **Fisher 比（方案 3.3）**：需要逐样本的特征。阶段一保存了特征，但没有上传，文件太大。
- **温度缩放（方案 4.3）**：需要源域验证集上的 logits，但现有运行都没有留验证集。
- **batch 大小对估计误差的影响（方案 3.2 后半）**：需要固定模型、改变 batch 重新抽样，要用到模型权重。
